# Asteroids gone rogue — palette notes

## World 1 (Arena_Blockout)
- Materials: `Mat_Arena` (cool blue-grey)
- Shape: closed octagon ring, pillars, radius ~22 m

## World 2 (Arena_World2_Blockout)
- Materials:
  - `Mat_Arena_W2_Floor` — warm dusty red-brown
  - `Mat_Arena_W2_Wall` — darker rust / burnt sienna
  - `Mat_Arena_W2_Accent` — orange-magenta hazard strips / rift
  - `Mat_Arena_W2_Glow` — ember cyan-orange gate lights
- Shape: **broken ring with cleft** (+X gap), gate pillars, inner rift plates, debris
- Scale: 1 unit = 1 m, playable radius ~22 m (same class as W1)
- Pivot: world origin (0,0,0) center of playfield

## World 3 (Arena_World3_Blockout)
- Materials: `Mat_Arena_W3_Floor/Wall/Accent/Glow` — cool teal/green
- Shape: twin-lane with center island/tower, end-gate gaps (not a ring)
- Scale: 1u=1m, ~22m class playfield
