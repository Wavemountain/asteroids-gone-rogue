# Layer gate

A layer bug (the dimmed W3/W4 beam plate, a ring drawn over enemies, a HUD line sitting on another line) must fail a gate before it is treated as a passing capture.

The decision lives in `Assets/Scripts/Core/LayerGate.cs`. `LayerGate.SelfCheck` injects each failure class and requires a FAIL string, then requires a clean scene to pass. `Tools/test_week1_logic.py` runs that self-check. `Tools/layer_gate_check.py` injects bad shader text and a `renderQueue = 4000` literal and requires those to FAIL as well.

Whitelist data: `Tools/layer_whitelist.json`.

## What fails

1. **Unknown renderer.** A visible renderer must match a renderer-name glob and a material-name glob. Patterns come from `renderers` / `materials` plus the shot's world (`hangar`, `1`, `3`, `4`, `death`, `waveclear`). Death and wave-clear also accept world `1`. A disabled renderer is ignored. `*_*` admits compound names; a stray single token such as `OlivePlate` with `Default-Material` does not.
2. **Dead plate.** A visible opaque renderer (queue under 2500) with emission luma ≤ 0.45 and albedo luma ≤ 0.45 fails when it is unlit or its name/material contains a `deadNameHints` token (`Beam`, `W3_Beam`, `W4_Glow`). That is the dimmed olive plate. An additive beam with alpha 0 is not visible, so it does not fail. `deadExempt` globs (belt asteroids, debris, smoke, bolt halo, telegraph rings) skip this check. A beam name still fails. A real contact shadow is not a dead plate. `DecorDepthClamp.KeepGameplay` never writes `renderQueue` on a shared material. A gameplay renderer whose authored queue is under 3000 and is not already 2450 gets its own material instance at 2450. `ContactBlob` and `Mat_ContactBlob` are not instanced, so the shared blob stays at the authored queue 2990 and still loses the depth test on mines and raised strips. The dead-plate exemption is only that shadow: a `ContactBlob` component or the material `Mat_ContactBlob`, alpha above `VisibleAlpha` (0.04), and a floor plate under the renderer (`FloorSurface.TryTop`). The shader name `AGR/BlobShadow` is not a waiver. Another material on that shader, or `Mat_ContactBlob` off the floor, still fails `dead`. Alpha at or under 0.04 on a real blob fails `shadow-alpha`. The object name is not a waiver. The capture still requires the blob under bodies.
3. **ZTest Always / Overlay queue.** A shader or material that depth-tests with Always, or sits at queue ≥ 4000, fails when it can draw over the ship, enemies, asteroids, pickups, or pillars. `AGR/Post` and `Hidden/*` are the post exemption. HUD canvases are not mesh renderers.
4. **Queue and sort.** Gameplay roles must use queue 2000–3999 (Geometry 2000–2449, AlphaTest 2450–2499, Transparent 2500–3999). A negative queue is the shader default, Geometry 2000. The dome ring (`ArenaLip` / `Mat_Env_Lip`) must use ZTest Less (2) or LEqual (4). `AgrDomeRing.shader` exposes `_ZTest` and samples it. Enabled canvases must use a `CanvasOrder` value (`Root` 0, `ShipPreview` 80, `HangarShop` 120, `Overlay` 150, `Rebind` 160, `Boon` 200, `Toast` 250).
5. **UI overlap.** Rect overlap and glyph boxes (`preferredWidth` / `preferredHeight`) fail the shot. That covers HUD-vs-HUD, HUD vs the hint row, and the hangar title / world / medal rows. The same measurement already logged `AgrCapture FAIL:`; the layer gate records it as `ui-overlap` too. `LayerGate.IsUiBackgroundPair` skips one explicit list, in both orders: `Hint x HintScrim` and `HintScrim x Hint`. HintScrim is the plate drawn behind the hint line, so that pair is a control on its own background, not two controls. `AgrCapture` skips the same pairs before it logs `hud overlap` or records a layer hit. Any other pair, including `WorldBadge x BadgeRow`, still fails. `Hint x ShipPreviewFrame` is not on the list. The hangar hint ends at `GameUi.HangarHintMaxY` (0.064) and `ShipPreviewMin.y` is 0.080, a gap of 0.016 (12.8 px at 800, 17.3 at 1080, 23.0 at 1440). Prompt segments are clamped inside the hint, so a real overlap is fixed in the rects rather than waived. The wave-clear hint is that same `Hint` row. `AgrCapture` measures each `PSegT` with `HintBoxPx` (`rect.height` times `|lossyScale.y|`) and fails when it is more than 1 px from the wave-1 segment stored on world `1`. `GameUi.FinishHintBox` records that wave-1 segment after layout (font, size, anchors, pivot, the canvas scale, and the screen box) and writes it onto the wave-clear segments after every paint and every `RefitPlayHint`. The copy does not apply the segment's `localScale`. Legacy dynamic text is already rasterized at `fontSize` times `canvas.scaleFactor`, so a second scale (or a rect grown to a screen box while `fontSize` stays in the old canvas units) magnifies the atlas texels. That is the smeared `HANGAR` row: the box still reads about 27 px, and the glyphs are bilinear blocks. Wave clear keeps the wave-1 `Font`, assigns `Canvas.GetDefaultCanvasMaterial` (the shared UI material, not `font.material`), sets a real `fontSize` for the current canvas scale, requests those glyphs with `Font.RequestCharactersInTexture`, forces `localScale` to 1, and snaps the rect to screen pixels. `resizeTextForBestFit` stays off. `AgrCapture` samples each `Hint`/`PSegT` in the captured frame. The capture image is 1920×1080. Batch mode's game view is smaller (the 048m log was 640×480), and overlay `GetWorldCorners` are game-view pixels, so using them as image coordinates reads a flat corner and prints `hint-soft 0.0 ref 0.0`. While the UI camera is aimed at the capture target, the gate stores each glyph's viewport rect (bottom-left origin, same as `ReadPixels`) and samples that. Luma is 0–255 (`LayerGate.GlyphLuma`). `LayerGate.LaplacianVariance` is the inverse 10–90% rise width at the sharp quintile (`RiseGlyphRank` 20) of edges whose bright end reaches the glyph ink (`RiseInkFraction` 0.55 of the crop range). An edge counts only when its span is at least 45% of the crop contrast, and each edge contributes one width, so empty pixels and extra letters do not change the score. A rise that never reaches the ink is backing, not a stem, and is dropped. The scrim ramp on a real stem is wider than the stem itself; it sits above the quintile and does not move the score. A short crisp row therefore matches a long one, and the plate behind the ink does not change the score either. The median did not: on the crisp 048x captures it sat at 0.54 for W4 and the hangar, and it swapped 0.71 with 0.87 on W3 and wave clear between the two modes, because the scrim under the same glyphs changed. The quintile on those same crops is 79.3–80.0 in both modes (ratio at least 0.99). A smeared glyph has no short ink rises, so the quintile widens. Raw Laplacian variance over every pixel scales with how much text the crop contains: the long wave-1 row was the reference, and shorter crisp rows (wave clear `HANGAR`, the hangar footer, death) landed near 0.29–0.56 and false-failed. A flat crop, or a reference under `GlyphReferenceFloor` (1), is `hint-soft error` and is logged as `AgrCapture layer ERROR:` — not a FAIL and not a pass. World `1` stores the sharpest segment. Any other hint whose score is under 0.9 of that reference (`LayerGate.GlyphSharpRatio`) fails as `hint-soft`. Wave clear copies the wave-1 font, size, colour, alignment, overflow, and material, keeps `resizeTextForBestFit` off and `localScale` at 1, and snaps the glyph rect onto whole pixels of the capture camera before that camera renders. `LayerGate.SelfCheck` still blurs a hard stem, and it loads every hint segment cut from the crisp 048x captures (`Tools/fixtures/hint/hint_<scene>_r<mode>_<index>.bmp`). The scenes are W1, W3, W4, death, hangar, and wave clear. Mode 0 is reduce off and mode 1 is reduce on. Segments are left to right, the same rects the capture scores. Each segment must clear `GlyphSharpMargin` (0.95) against that mode's best wave-1 segment, so the runtime line at 0.9 has margin. A two-pass box blur of that same segment must land under `GlyphBlurCeiling` (0.5) and fail as `hint-soft`. `hint_flat.bmp` must error. The two modes of one segment must agree within `GlyphModeGap` (0.05). The flat-crop and reference-under-floor path stays `hint-soft error`.
6. **Contact shadow.** Every active `ShipController`, `EnemySeeker`, and `Asteroid` needs an enabled child renderer named `ContactBlob`, on that body's XZ, just above the floor (`FloorSurface` raycast or renderer bounds, then 0.02–0.05 m). The quad radius is 2× the footprint and the centre alpha is 0.9. Spawn paths call `ContactBlob.Attach` (`CastFormShadow`, plus a LateUpdate ensure on the ship, enemies, and asteroids) so a pooled or late mesh still gets a blob. `AgrCapture` then reads the frame. The local floor is a ring just outside the blob. When that luma is above 0.06, the shadow sample must be at least 15% darker. When the local floor luma is 0.06 or lower, a percentage is not visible, so the shot does not use a pixel threshold: the blob renderer must be enabled, active, in view when the body is near the ship, and sitting on the body. W3's floor is in that dark band. W4 is bright enough for the 15% test. W1's spawn disc can be the local surface; if that disc is at or under 0.06, W1 uses the same renderer check, and the separate spawn-disc contrast sample (framebuffer pixels on the disc, outside the blob) still has to reach 1.3.
7. **UI camera and canvas layer.** Every enabled canvas must sit on the built-in UI layer (`LayerGate.UiLayer`, 5). `GameUi.UseUiLayer` assigns that layer wherever a canvas is created, including nested canvases (`RaiseCanvas`, the shop, the prompt, the rebind overlay). The capture overlay camera (`AgrCaptureUiCamera`) must use `cullingMask = LayerGate.UiCameraMask` (`1 << 5`) and must sit at `(0, -10000, 0)`, so it cannot redraw the ship or other Default-layer objects on top of the HUD. A mask that includes any other layer fails as `ui-camera`. A canvas on another layer fails as `canvas-layer`. The hangar preview camera stays on layer 8 and is not a UI camera.
8. **Decor near spawn.** Each arena blockout is one mesh. `SpawnClear.ClearVisual`, called from `ApplyArenaForWave`, copies that mesh and drops a connected island when its closest XZ point is within 4 of the origin and its farthest XZ point is within 8. That removes the W3 centre plate and glow pillar, the W2 pads, the W4 pillar, the W5 plinth and pillar, and the W6 plinth. The floor and the W4 lane walls stay, because they reach farther than 8. The same pass drops a compact corner island that straddles the lip (at least 3 inside the arena radius and at least 4 outside, both spans between 3 and 12) so the W4 ring stays continuous. A capture that still finds a spawn island fails as `spawn-decor`. An unreadable mesh reports the renderer's world bounds, not a zero box at the origin. Children under `Arena_Layout` (hazard spikes on the cross) are not blockout islands. A death shot with live `Smoke` particles fails as `death-remnant Smoke`. A ship with no enabled hull renderer is not an active body, so a shattered ship does not fail `contact-shadow`.

## Static vs runtime

| Check | Static (`validate_week1_project.py` → `layer_gate_check.py`) | Runtime (`AgrCapture.CheckLayer`, every shot) |
| --- | --- | --- |
| Whitelist file, keys, `Mat_*`, `Beam` hint, `canvasSorts` == `CanvasOrder` | Yes | Reads the same JSON. A missing or broken file is a FAIL. |
| Unknown renderer / material | Self-check only (injected facts) | Yes, per visible renderer |
| Dead plate | Self-check only | Yes |
| `ZTest Always` in `*.shader` | Yes, unless the shader is exempt | Yes, when the material has `_ZTest` == 8 |
| `Queue="Overlay"` and `renderQueue >= 4000` | Yes | Yes, queue ≥ 4000 on a non-post renderer |
| Gameplay queue outside 2000–3999 | Self-check only | Yes |
| Dome ring depth test | `AgrDomeRing.shader` must use `ZTest [_ZTest]` and must not say `ZTest Always` | Yes, role `dome` |
| Canvas sort uses `CanvasOrder` | Source assignments (existing canvas check) plus the whitelist list | Yes, every enabled `Canvas` |
| UI overlap, including glyphs and hangar rows | Self-check only | Yes, all six shots |
| Hint glyph sharpness (`hint-soft`) | Self-check blurs a hard stem and loads every 048x hint segment in `Tools/fixtures/hint` (W1, W3, W4, death, hangar, wave clear, both modes). Each crisp segment passes at ≥ 0.95 of that mode's wave 1. A box blur of each fails under 0.5. `hint_flat.bmp` errors. The two modes agree within 0.05 | Yes. The UI camera's viewport crop, luma 0–255. The score is the inverse sharp-quintile 10–90% rise of edges that reach the glyph ink, so text length and the scrim do not change it. World `1` stores the sharpest `Hint`/`PSegT`. Another hint under 0.9 of that reference fails. A flat crop or a reference under 1 is `hint-soft error` |
| Contact shadow present | Self-check only | Yes. Darkness is separate: luma above 0.06 needs 15% darkening; a darker floor needs the blob renderer enabled and placed |
| Canvas on the UI layer (5) | `GameUi.cs` and `RebindOverlay.cs` must call `UseUiLayer` next to every `AddComponent<Canvas>`. An injected canvas without that call FAILs | Yes, every enabled `Canvas` |
| Capture/UI camera mask is UI-only | `AgrCapture` must set `cullingMask = LayerGate.UiCameraMask` and park the camera at `(0, -10000, 0)`. A mask built from canvas layers FAILs | Yes, the overlay camera used for that shot |
| Decor island within 4 of spawn and no farther than 8 | `ContentFactory` must call `SpawnClear.ClearVisual`. `SpawnClear` must use `IsSpawnClutter` and `IsRingCorner`. `AgrCapture` must call `CollectSpawnIslands`. An injected source missing those calls FAILs | Yes, every shot, from the live blockout mesh |

A runtime hit logs `AgrCapture layer FAIL:` and does **not** stop the remaining shots. The process still exits non-zero (`CaptureContinue.ExitCode` with the layer flag). A fatal capture error (missing session, empty frame) still stops the run.

## Adding a legal object

Add the renderer glob and, if it is not `Mat_*`, the material glob to `Tools/layer_whitelist.json`. World-only props go under `renderers.<world>` or `materials.<world>`. Then run:

```
python3 Tools/validate_week1_project.py
python3 Tools/test_week1_logic.py
```
